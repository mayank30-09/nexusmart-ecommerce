# NexusMart E-Commerce Platform — Software Requirements Traceability Matrix (RTM)

## 1. Executive Summary & Purpose

This Software Requirements Traceability Matrix (RTM) establishes comprehensive, bidirectional traceability between:
1. **Academic Software Engineering Syllabus & Practical Requirements** (BTCO13702, Practical 3 through Practical 11, UML/DFD specifications, PRESSMAN SQA standards).
2. **Software Requirements Specification (SRS)** (Extracted from Practical 4: *Create Software Requirement Specification (SRS) for your System*, BTCO13702 Course Specifications).
3. **Architecture & Implementation Evidence** (Routes, services, database tables, and Jinja2 templates in `ecommerce_practical10/`).
4. **Verification Evidence** (148 Pytest automated tests, 37 Unittest legacy tests, and 25 Playwright end-to-end browser test scenarios with 25 verified screenshots).

## 3. Business Rules Compliance Matrix (BR-01 to BR-06)

|---|---|---|---|---|

| **BR-02** | **Discount Boundary Enforcement**: Applied discount amount cannot exceed cart subtotal; final payable total cannot be negative ($\ge$ ₹0.00). | `app.py:evaluate_coupon` enforces `min(discount, subtotal)` and `max(0.0, final_total)`. | `test_checkout_discounts.py:test_11_discount_boundary_and_rounding` | **PASS** |
| **BR-03** | **Single Active Coupon per Checkout**: Only one promotional coupon may be applied per customer cart at any given time. | Session holds atomic string `applied_coupon`; applying a new coupon cleanly replaces existing. | `test_checkout_discounts.py` & `test_orders_payments.py` | **PASS** |
| **BR-04** | **Order Cancellation Lock**: Customer order cancellation is strictly prohibited once order status is transitioned to `Shipped` or `Delivered`. | `app.py:cancel_order` blocks cancellation if `order_status in ['Shipped', 'Delivered']` with explicit error flash. | `test_admin_and_recommendations.py:test_09_admin_order_status_and_br04_cancellation_lock` | **PASS** |
| **BR-05** | **Address Default Exclusivity**: A customer may designate at most one shipping address as default.
