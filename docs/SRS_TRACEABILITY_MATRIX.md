# NexusMart E-Commerce Platform — Software Requirements Traceability Matrix (RTM)

## 1. Executive Summary & Purpose

This Software Requirements Traceability Matrix (RTM) establishes bidirectional traceability between:
1. **Academic Software Engineering Syllabus & Practical Requirements** (BTCO13702, Practical 3 through Practical 11, UML/DFD specifications, PRESSMAN SQA standards).
2. **Software Requirements Specification (SRS)** (Extracted from Practical 4: *Create Software Requirement Specification (SRS) for your System*).
3. **Architecture & Implementation Evidence** (Routes, services, database tables, and Jinja2 templates in `ecommerce_practical10/`).
4. **Verification Evidence** (135 Pytest automated tests, 37 Unittest legacy tests, and Playwright end-to-end browser test suites).
